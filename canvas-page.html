👨‍💻 Code-Together 7: Singly Linked List Introduction

🎯 Overview

An in-class code-together activity introducing singly linked lists through a Farr's Ice Cream ticket queue scenario. Students implement all core list operations — destructor, push/pop front & back, and print — by completing TODO items as the instructor walks through concepts and diagrams. Search and remove operations are covered in CT8.

Step 2: Clone in Visual Studio

  1. Open Visual Studio

📝 What You’ll Do

Open each source file and complete the TODO comments. Each TODO tells you what to write, and the DISCUSSION comments explain the “why” behind the code. We’ll work through these together in class.

🖼️ Diagrams

Diagrams are included in the images/ folder and referenced in the source code comments. These help visualize what’s happening:

Diagram Shows
node_vs_array Structural comparison of array contiguous memory vs linked node chain
destructor_walk Traversing the chain with temp pointer, deleting each node
push_front New node's next points to old head, then head moves to new node
push_back Traversing to the last node, then linking the new node
pop_front Save head into temp, advance head, delete temp
pop_back Trailing pointer pattern: previous/current traversal, unlink and delete last node

🔧 Troubleshooting

CMake does not configure automatically

  1. Make sure you have Desktop development with C++ workload installed in Visual Studio
  2. Go to Project → CMake Settings and ensure the configuration is correct
  3. Try Project → Delete Cache and Reconfigure
  4. Verify that CMakeLists.txt is in the root of your cloned repository

Tests fail to build

  • Google Test is fetched automatically via CMake’s FetchContent — make sure you have an internet connection during the first build
  • Do not modify header files in the include/ folder

Running the Program

  1. In Visual Studio, select ct7-linked-lists-intro.exe as the startup item from the dropdown
  2. Press Ctrl+F5 to run without debugging
  3. You should see output from each section as you complete the TODOs
Tip: Look for the // ! DISCUSSION: comments in each file — these explain the “why” behind each concept. The // ? SEE DIAGRAM: comments point you to visual aids in the images/ folder.
